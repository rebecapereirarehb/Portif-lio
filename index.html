Sistema de Cadastro — GOES

Sistema de gestão para ONG (Python + SQLite + Tkinter)

Acessar repositório ↗

Sistema desktop completo desenvolvido como Atividade Extensionista da faculdade para o Grupo Gotas de Esperança (GOES), ONG de Paranavaí-PR onde atuei como educadora social. A aplicação organiza o dia a dia da instituição em um único lugar.

Módulos desenvolvidos: cadastro de assistidos, visitas domiciliares, entrega de cestas básicas, eventos, controle de presença, encaminhamentos e geração de relatórios.
