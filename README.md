# Portfólio — Rebeca Pereira Rodrigues

Portfólio pessoal desenvolvido para apresentar minha trajetória acadêmica,
conhecimentos, projetos e objetivos profissionais na área de tecnologia.

## Sobre o projeto

Este projeto foi desenvolvido utilizando HTML, CSS e JavaScript puro,
sem o uso de frameworks ou bibliotecas.

O portfólio apresenta:

- Informações sobre mim
- Formação acadêmica
- Conhecimentos e tecnologias
- Projetos desenvolvidos
- Informações para contato

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Navegação entre páginas
- Tema claro e escuro
- Menu responsivo para dispositivos móveis
- Validação do formulário de contato
- Layout responsivo
- Armazenamento da preferência de tema utilizando `localStorage`
